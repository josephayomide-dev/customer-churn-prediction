Customer Churn Prediction Using Python and Machine Learning

Overview
A machine learning project that predicts whether telecommunications customers are likely to leave.

Dataset
IBM Telco Customer Churn dataset (7,043 records).

Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Google Colab.

Workflow
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Feature encoding
- Model training and evaluation
- Classification threshold experimentation

Models
- Random Forest
- Logistic Regression

Results
- Random Forest accuracy: 78.8%
- Logistic Regression F1-score (0.5): 61.3%
- Logistic Regression churn recall (0.3): 92.5%
